# Romantic Proposal Website 💖 (Python)

A cute, interactive romantic webpage using **Flask** with:
- A playful **"No"** button that moves away
- A **"Yes"** flow with sweet follow-up questions
- A happy ending popup
- Romantic theme and styling

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open: `http://127.0.0.1:5000`

## Structure

- `app.py`
- `templates/index.html`
- `static/styles.css`
- `static/script.js`
- `requirements.txt`
